## 📖 详细使用步骤

### 场景1：仅需对预测数据进行风险标注

**最简单的方式**：

```bash
# 1. 确保预测数据文件名为：原始预测结果.csv
# 2. 运行脚本
python 应用风险标注模型.py

# 3. 查看结果
# 输出文件：预测结果_带风险标注.csv
```

**结果说明**：
- `理赔差额` = 索赔金额 - 预测赔付金额
- `数分位指标` = 理赔差额 / (预测赔付金额 + 1)
- `风险标注` = 合理诉求 / 诉求偏高 / 严重超额

## ⚡ 常见操作

### 修改预测数据文件名

如果预测数据文件名不是 `原始预测结果.csv`，需要修改 `应用风险标注模型.py`：

```python
# 第77行
predict_df = pd.read_csv('你的文件名.csv')  # 修改这里
```

### 查看风险标注分布

```python
import pandas as pd

# 读取结果
df = pd.read_csv('预测结果_带风险标注.csv')

# 查看分布
print(df['风险标注'].value_counts())
print(df['风险标注'].value_counts(normalize=True) * 100)
```

### 筛选高风险案例

```python
# 筛选诉求偏高和严重超额
high_risk = df[df['风险标注'].isin(['诉求偏高', '严重超额'])]
print(f"高风险案例数：{len(high_risk)}")
```

## ❓ 遇到问题？

### 问题1：找不到文件

**错误**：`FileNotFoundError: train_processed.csv`

**解决**：
- 确保数据文件在正确目录
- 检查文件名是否正确
- 检查文件路径

### 问题2：列名不匹配

**错误**：`KeyError: '预测赔付金额'`

**解决**：
- 检查预测数据是否包含必需列
- 确认列名拼写正确（注意中英文）

### 问题3：编码错误

**错误**：编码相关错误

**解决**：
- 确保CSV文件使用UTF-8编码
- 或修改代码中的`encoding`参数
