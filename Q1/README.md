# 理赔风险标注项目文档

## 📋 项目概述

本项目基于**分位数回归（Quantile Regression）**技术，对理赔案例进行风险标注分类。项目主要功能包括：
- 训练分位数回归模型进行风险标注
- 对新数据进行风险标注预测
- 生成混淆矩阵和预测指标分析
- 可视化结果展示

### 风险标注类别

项目将理赔案例分为三个风险等级：
- **合理诉求**：占比≥85%
- **诉求偏高**：占比约12%
- **严重超额**：占比<3%

## 🔧 技术路线

### 核心技术：分位数回归（Quantile Regression）

项目采用分位数回归而非普通线性回归的原因：
1. **数据分布特性**：数分位指标呈现右偏分布，存在异常值
2. **业务需求**：需要识别不同风险水平的分界点（85%、97%分位数）
3. **稳健性**：对异常值更稳健，适合金融数据

### 核心指标：数分位指标

```python
数分位指标 = 理赔差额 / (实际赔付金额 + 1)
```

**指标含义**：
- 量化理赔差额相对于实际赔付的倍数关系
- 值越大，说明索赔金额越远超实际赔付，风险越高

**分母加1的原因**：
- 防止除零错误
- 稳定指标计算

### 模型参数

- **85%分位数模型**：用于区分"合理诉求"和"诉求偏高"
- **97%分位数模型**：用于区分"诉求偏高"和"严重超额"
- **正则化参数**：`alpha=0.1`

### 风险标注规则

```python
if 数分位指标 <= 85%分位数预测值:
    风险标注 = "合理诉求"
elif 数分位指标 <= 97%分位数预测值:
    风险标注 = "诉求偏高"
else:
    风险标注 = "严重超额"
```

## ⚙️ 技术细节

### 数据预处理流程

1. **特征选择**：
   - 排除列：`索赔金额`、`实际赔付金额`、`数分位指标`、`虚报比例`
   - 使用30个特征进行回归

2. **分类变量编码**：
   - 使用`LabelEncoder`进行编码

3. **缺失值处理**：
   - 使用中位数填充

4. **特征标准化**：
   - 使用`StandardScaler`进行标准化

### 模型训练

```python
from sklearn.linear_model import QuantileRegressor

# 85%分位数模型
model_85 = QuantileRegressor(quantile=0.85, alpha=0.1)
model_85.fit(X_scaled, y)

# 97%分位数模型
model_97 = QuantileRegressor(quantile=0.97, alpha=0.1)
model_97.fit(X_scaled, y)
```

### 模型评估

- **交叉验证**：5折交叉验证，使用MAE（平均绝对误差）评估
- **85%分位数模型**：CV MAE ≈ 3.65
- **97%分位数模型**：CV MAE ≈ 11.04

## ⚠️ 注意事项

### 1. 数据匹配问题

- 预测数据和训练数据可能无法完全匹配样本
- 混淆矩阵可能基于分布假设而非真实匹配
- 建议确保预测数据与训练数据来自相同的特征空间

### 2. 模型一致性

- 确保预测数据使用与训练数据相同的预处理流程
- 特征编码器需要使用训练数据训练得到的编码器
- 标准化参数需要使用训练数据的scaler

### 3. 预测赔付金额

- 预测数据中的"预测赔付金额"对应训练数据中的"实际赔付金额"
- 在计算数分位指标时，使用"预测赔付金额"代替"实际赔付金额"

### 4. 缺失特征处理

- 如果预测数据缺少某些训练时使用的特征，脚本会用0填充
- 建议确保预测数据包含所有必要的特征

### 5. 严重超额类别

- 预测数据中可能没有"严重超额"类别的样本
- 这是由于模型预测结果分布与训练数据分布存在差异

## 🔍 常见问题

### Q1: 为什么预测数据中没有"严重超额"类别？

**A**: 这可能是因为：
- 预测数据的整体风险水平较低
- 模型对新数据的预测偏向于保守
- 分位数阈值在新数据上的表现与训练数据不同

### Q2: 如何调整风险标注的阈值？

**A**: 可以修改`应用风险标注模型.py`中的分位数参数：
```python
quantiles = [0.85, 0.97]  # 可以根据需要调整
```

### Q3: 混淆矩阵显示为0是否正确？

**A**: 如果无法匹配样本，混淆矩阵会基于分布假设估算。建议：
- 确保两个数据集有共同的标识符（如运单号）
- 或使用更精确的匹配字段组合
